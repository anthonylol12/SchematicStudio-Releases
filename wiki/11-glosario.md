# 11. Glosario: palabras que salen en el programa

[← Preguntas frecuentes](10-preguntas-frecuentes.md) · [Índice](README.md) · [Siguiente: Datos técnicos →](12-datos.md)

| Palabra | Qué significa |
|---|---|
| **Schematic** | Archivo que guarda una construcción de Minecraft para copiarla o compartirla. |
| **WorldEdit** | Plugin/mod muy usado para copiar y pegar construcciones (`//copy`, `//paste`, `//schem save`). |
| **Litematica** | Mod que muestra una construcción como un «holograma» para construirla a mano. |
| **Bloque de estructuras** | Bloque del propio Minecraft que guarda y carga construcciones `.nbt`. |
| **Formato** | Tipo de archivo: `.schem`, `.schematic`, `.litematic` o `.nbt`. |
| **Versión** | La versión de Minecraft (1.12.2, 1.20.1, 1.21…). Cada una tiene bloques distintos. |
| **DataVersion** | Número interno con el que Minecraft marca la versión de un archivo (por ejemplo 3465 = 1.20.1). El programa lo traduce a la versión. |
| **Legacy** | Versiones 1.12.2 y anteriores, que usan números (ID y data) en vez de nombres para los bloques. |
| **ID / data** | En versiones legacy, el número del bloque (1 = piedra) y su variante (1:1 = granito). |
| **Identificador** | Nombre interno de un bloque en 1.13+, como `minecraft:oak_planks`. |
| **Estado de bloque** | Un bloque con sus propiedades: `oak_stairs[facing=north,half=bottom]` = escalera de roble mirando al norte, en la parte de abajo. |
| **facing** | Hacia dónde mira el bloque: north (norte), south (sur), east (este), west (oeste), up (arriba), down (abajo). |
| **waterlogged** | Si el bloque tiene agua dentro (existe desde 1.13). |
| **Entidad de bloque** | Bloque con contenido: cofres, hornos, carteles, estandartes… |
| **Entidad** | Cosas que no son bloques: soportes de armadura, cuadros, animales. |
| **Origen (punto de pegado)** | Bloque de la construcción que queda donde está el jugador al pegar. En el visor, el bloque magenta. |
| **Posición en el mundo** | Coordenadas reales donde estaba la construcción cuando se copió. |
| **Sustituto** | Bloque que se pone en lugar de otro que no existe en la versión de destino. |
| **Similitud** | Lo parecido que es un sustituto al original (100 % = idéntico). |
| **Regla** | Sustitución que guardas para que se aplique sola en el futuro. |
| **Pincel** | Bloque elegido para reemplazar al editar. |
| **Proyecto (.ssproj)** | Archivo de Schematic Studio que guarda tu trabajo completo para seguir otro día. |
| **Exportar** | Guardar la construcción en un archivo nuevo para Minecraft. |
| **Structure void** | Posiciones «vacías» de una estructura `.nbt`: al colocarla, no cambian lo que ya hay en el mundo. |
| **X, Y, Z** | Ejes: X = este/oeste (rojo), Y = arriba/abajo (verde), Z = norte/sur (azul). |
